# Requirements Document

## Introduction
This document contains documentation about requirements.
### Goals

#### Document Goals
Document and update requirements.
#### Problem Description
The customer needs a generic e-commerce, with products, customers and purchase products.
#### System Description
The system is an online e-commerce platform that manages Products, Customers, Cart and Payments.

The system contains the next entities:
- Product → something the store sells
- Customer → person who purchases products
- Cart → collection of products selected by a customer
- Order → a confirmed purchase request
- Payment → payment associated with an order

## Requirements

### Introduction
The requirements are validated and prioritized in association with the customer.

Customer management

Shopping cart
- UR-008 - Add a product to the cart.

Ordering
- UR-012 - Place an order.

Payment
